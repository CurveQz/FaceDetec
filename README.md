Code Review: FaceDetec

Repo: https://github.com/CurveQz/FaceDetec ไฟล์ที่รีวิว: faceRec.py, FaceTrain.py ผู้ตรวจ: นัธทวัฒน์ อุ่มญาติ สรุปสั้นๆ: เป็น proof-of-concept ระบบจดจำใบหน้าด้วย KNN บนพิกเซลดิบ (dataset ที่ใช้เป็นข้อมูลทดสอบระบบ) ใช้งานได้จริงในเดโมส่วนตัว แต่ยังมีข้อจำกัดเชิงเทคนิคที่ควรแก้ก่อนใช้งานจริง

1. ภาพรวมของระบบ

โปรเจกต์นี้มี 2 สคริปต์ทำงานคู่กัน:

ไฟล์	หน้าที่
faceRec.py	เปิดกล้อง, ครอปกรอบตำแหน่งคงที่ (210:430, 100:380), เซฟเป็นภาพขาวดำลงโฟลเดอร์ตามชื่อคน (dataset collector)
FaceTrain.py	โหลดภาพทุกโฟลเดอร์ (= ทุกคน) มาทำ KNN แบบ from-scratch แล้วรันกล้อง real-time เพื่อทาย "ใครอยู่ในกรอบ"

ชื่อไฟล์สลับกับหน้าที่นิดหน่อย (FaceTrain.py ทำทั้งเทรนและ predict, faceRec.py จริงๆ คือตัวเก็บข้อมูล) แต่ไม่กระทบการทำงาน เป็นเรื่อง naming เท่านั้น

จุดที่ทำถูกและน่าชม:

กรอบครอบที่ใช้ตอนเก็บภาพ (faceRec.py) กับตอนทำนาย (FaceTrain.py) เป็นพิกัดเดียวกันทุกตัว (210:430, 100:380) ทำให้รูปทุกใบมีขนาดเท่ากันเป๊ะ (220×280) — แก้ปัญหา shape ไม่ตรงกันที่เคยพบในโค้ดเวอร์ชันก่อนหน้าไปแล้ว
มีการรับมือกล้องอ่านเฟรมไม่ทัน (fail counter) และปิดโปรแกรมได้หลายทาง (q, Esc, กดปิดหน้าต่าง)
ตัวเลขไฟล์เก็บภาพต่อจากของเดิม ไม่ทับไฟล์เก่า
2. ปัญหาเชิงแนวคิด (สำคัญที่สุด)
2.1 นี่ไม่ใช่ "face detection" แต่เป็น "region matching"

ระบบไม่มีตัวตรวจจับใบหน้า (ไม่มี Haar cascade, ไม่มี face landmark ใดๆ) กรอบสี่เหลี่ยมเป็นตำแหน่งคงที่บนจอเท่านั้น ถ้าคนขยับหัวออกนอกกรอบ เอียงหน้า หรือมีคนอื่นเดินผ่านในกรอบนั้น ระบบจะเทียบพิกเซลของสิ่งที่อยู่ในกรอบ ไม่ใช่ของใบหน้าจริงๆ — พูดง่ายๆ คือระบบ "เดา" จากตำแหน่งที่นั่ง ไม่ได้ "รู้จัก" ใบหน้า

2.2 ไม่มี threshold / ไม่รองรับคนแปลกหน้า (open-set problem)

knn() จะทายชื่อคนใดคนหนึ่งเสมอ แม้ภาพที่เห็นจะไม่ใช่ทั้ง Nut และ Tonkla เลยก็ตาม เพราะ KNN เลือกจากระยะทางที่ใกล้ที่สุดในบรรดาคนที่มีอยู่ ไม่มีการเช็คว่าระยะนั้น "ใกล้พอจะเชื่อได้" หรือเปล่า ผลคือคนแปลกหน้าจะถูกจัดว่าเป็นคนใดคนหนึ่งในระบบเสมอ

2.3 ระยะพิกเซลดิบไวต่อแสง/มุม/สีหน้ามาก

KNN เทียบระยะแบบ Euclidean บนพิกเซลตรงๆ (ไม่มี normalize, ไม่มี feature extraction) แปลว่าความสว่างของห้อง มุมกล้อง หรือแม้แต่ใส่แว่น มีผลต่อผลทายนายมากกว่าที่ควร โมเดลจะ "จำสภาพแวดล้อมตอนถ่าย" มากกว่า "จำใบหน้า"
